# Pokemon-card-database
# Sistema de Batalhas Pokémon - CARD

Projeto de Banco de Dados desenvolvido para a disciplina **Banco de Dados I**
do curso de **Análise e Desenvolvimento de Sistemas – IFPB**.

## 🎯 Objetivo
Modelar um banco de dados que permita:
- Cadastro de Pokémons (Pokédex)
- Criação de times por treinadores
- Simulação de batalhas entre times Pokémon

## 🧠 Minimundo
Treinadores podem montar times com até 6 Pokémons distintos.
As batalhas acontecem por posição, e o Pokémon com maior poder vence a rodada.

## 🗂️ Estrutura do Projeto
- `docs/` → Documentação do projeto
- `sql/` → Scripts SQL (DDL, DML e consultas)
- `diagrams/` → Modelos do BrModelo

## 🛠️ Tecnologias
- SQL
- PostgreSQL / MySQL (adaptável)
- BrModelo Web
